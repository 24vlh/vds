Description List

Description lists present semantic key/value metadata using native dl, dt, and dd elements.

Source truth

Imports and metadata gap

Description lists are authored in src/components/description-list.css and ship through dist/components/description-list.css. Generated metadata currently has incomplete source_css evidence. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/description-list.css";

Accessibility

Keep the native relationship

Do not replace dt and dd with generic divs. Long values should wrap rather than clipping meaning.

  • Use description-list--inline, --stacked, --columns, or density modifiers for visual layout only.
  • Consumer code owns links, copy actions, truncation policy, and update announcements.
