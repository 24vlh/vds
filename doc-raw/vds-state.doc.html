Accessibility

Empty-state boundaries

Consumer code decides when the empty state appears and what the action does.

  • Use real headings and action labels.
  • Mark decorative icon/media slots with aria-hidden="true".
  • Use feedback, progress, or skeleton components for live status, errors, and loading lifecycle.
