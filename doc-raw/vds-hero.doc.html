Intro

Hero

Hero CSS styles page intros, media, CTA groups, metrics, points, loading skeletons, error states, full/inset surfaces, and responsive splits. CSS owns the intro layout; product code owns content, routing, loading/error state, and media alternatives.

Source truth

Imports and package surface

Hero is authored in src/components/hero.css and ships through dist/components/hero.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/hero.css";

Accessibility

Content and lifecycle ownership

CSS does not choose the heading level, load media, compute metrics, route CTAs, or decide when loading and error surfaces appear.

  • Keep one page-level heading outside or inside the hero according to the page outline.
  • Provide meaningful alt text or empty alt for decorative media.
  • Use text labels for error and metric meaning; do not rely on color alone.
  • Application code owns loading skeleton lifecycle, error remediation, CTA behavior, analytics, and live announcements.
