Forms

Forms

Forms style labels, fields, native controls, help text, messages, choices, file surfaces, grids, and validation states. Submission, validation, masking, and announcements are application-owned.

Source truth

Imports

Core forms are authored in src/components/forms.css and ship through dist/components/forms.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/forms.css";

Example

Labeled field with help and error wiring

Use labels, IDs, aria-describedby, and aria-invalid together. CSS only supplies visual hooks for the state.

Use a work email address.

<label class="form-label" for="profile-email">Email</label>
<input class="form-control form-control--error" id="profile-email" name="email" type="email"
       aria-invalid="true" aria-describedby="profile-email-help">
<p class="form-help form-help--error" id="profile-email-help">Use a work email address.</p>

States

Disabled, readonly, loading, and file handling

State classes and ARIA aliases must match actual behavior. File upload handling is not provided by CSS.

  • Use native disabled for unavailable controls when possible.
  • Use readonly only when the value remains focusable and copyable.
  • Use aria-busy="true" and visible text when async state changes matter.
  • Application code owns validation, submit prevention, file size/type checks, and live announcements.

Validation

Example quality and release checks

Source truth and package-facing imports must stay aligned: authoring evidence lives under src/, while copyable consumer imports use dist/. Validate examples in narrow and wide viewports, active themes, reduced-motion, forced-colors, and high-contrast contexts.

  • Examples must remain source-backed, copy-safe, and realistic enough to adapt.
  • Application code owns runtime JavaScript, ARIA synchronization, focus, keyboard, routing, lifecycle, and announcements.
  • Responsive, theme, motion, and contrast behavior must be checked in the consuming layout.
  • Migration and release notes must record any changed selector, token, import, or example contract.
