Navigation

Header and Footer

Header/footer CSS styles site chrome, nav slots, mobile panel hooks, skip links, sticky/elevated headers, app shells, footer columns, metadata, and action areas.

Source truth

Imports

Header/footer is authored in src/components/header-footer.css and ships through dist/components/header-footer.css. It composes with navigation and identity. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/navigation.css";
@import "@24vlh/vds/dist/components/header-footer.css";
@import "@24vlh/vds/dist/identity.css";

Example

Responsive header

The mobile toggle is only a visual hook until application code controls open state and focus. 

<header class="header header--sticky">
  <a class="skip-link" href="/docs/header-footer/main">Skip to content</a>
  <div class="header__inner">
    <a class="logo" href="/docs/header-footer/home" aria-label="VDS home">VDS</a>
    <nav class="nav" aria-label="Primary">
      <a class="nav__link nav__link--active" href="/docs/header-footer/home" aria-current="page">Home</a>
    </nav>
    <button class="header__toggle" type="button" aria-expanded="false" aria-controls="mobile-header-nav">Menu</button>
  </div>
</header>
