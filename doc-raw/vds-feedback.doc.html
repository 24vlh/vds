Feedback

Feedback CSS styles alerts, banners, feedback toasts, statuses, info blocks, guidance blocks, results, and progress-adjacent surfaces. Dismissal and announcement timing are application-owned.

Source truth

Imports

Feedback is authored in src/components/feedback.css and ships through dist/components/feedback.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/feedback.css";

Example

Alert with dismissal

A close button must have a name. Consumer code owns removal, focus behavior, and any follow-up announcement.

Deployment delayed

The release waits for one required review.

<div class="alert" data-variant="warning" role="status" aria-live="polite">
  <strong class="alert__title">Deployment delayed</strong>
  <button class="alert__close" type="button" aria-label="Close deployment delay alert"></button>
</div>

Accessibility

Status meaning

Feedback meaning must be available as text, not color alone.

  • Use role="status" for polite updates and role="alert" for urgent errors.
  • Do not use feedback blocks for form validation unless controls are wired with aria-describedby.
  • Application code owns dismissal, retry, validation lifecycle, and live announcements.
