Avatar

Avatar CSS styles people, teams, and entity images, initials, status dots, and groups. CSS owns sizing, shape, tone, status placement, and grouping; the application owns identity data and text alternatives.

Source truth

Imports and package surface

Avatar is authored in src/components/avatar.css and ships through dist/components/avatar.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/avatar.css";

Examples

Image, initials, status, and group

Use meaningful image alt text when the avatar identifies a person. Hide decorative presence dots and pair status with visible or adjacent text.

Accessibility

Identity and presence ownership

CSS cannot decide whether an avatar is informative or decorative, nor can it announce live presence changes.

  • Use alt="" only when nearby text already names the person or entity.
  • Do not communicate availability with the status dot alone.
  • Application code owns profile links, tooltip content, live presence updates, and group counts.
  • Validate image contrast and status visibility in the final theme and surface.
