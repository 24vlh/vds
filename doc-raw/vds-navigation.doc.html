Navigation

Navigation CSS styles primary navs, sidebars, breadcrumbs, pagination, toolbars, mobile panels, backdrops, and announcement bars. Routing and state synchronization are application-owned.

Source truth

Imports

Navigation is authored in src/components/navigation.css and ships through dist/components/navigation.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/navigation.css";

Open state hooks

CSS exposes nav-panel--open and nav-backdrop--visible. JavaScript owns mobile menu state, aria-expanded, aria-controls, Escape, outside-click, and focus return. 

<button class="nav__toggle" type="button" aria-expanded="false" aria-controls="mobile-nav">
  Menu
</button>
