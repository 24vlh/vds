Progress

Progress CSS styles determinate and indeterminate bars, labels, metadata, semantic variants, stripes, animation hooks, and steppers. Values and wizard state are application-owned.

Source truth

Imports and metadata gap

Progress is authored in src/components/progress.css and ships through dist/components/progress.css. Generated metadata currently has incomplete source_css evidence. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/progress.css";

Examples

Determinate and indeterminate progress

Determinate progress needs numeric ARIA values. Indeterminate progress omits aria-valuenow and uses descriptive text.

Storage used 68% 
<div class="progress" role="progressbar" aria-label="Storage used"
     aria-valuemin="0" aria-valuemax="100" aria-valuenow="68"
     style="--progress-value: 68%;">...</div>
