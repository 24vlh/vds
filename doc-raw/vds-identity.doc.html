Foundation

Identity

Identity styles inline SVG logo lockups, marks, wordmarks, color modes, sizing, and clearspace. It is a standalone package surface, not a component CSS file under src/components.

Source truth

Standalone import

Identity is authored in src/identity.css and ships through dist/identity.css and dist/identity.min.css. No dist/components/identity.css output is expected. 

@import "@24vlh/vds/dist/identity.css";
@import "@24vlh/vds/dist/themes/graphite.css";

Inline SVG logo classes can inherit theme tokens. External static logo assets have their colors baked into the asset.

Anatomy

Logo classes

The CSS covers the root logo, frame, rail, chevron, wordmark, text, KeepExec helpers, size modifiers, layout modifiers, clearspace, and color modes.

Copy-safe example

Linked logo

A logo link needs an accessible name that describes the destination, not just the image. 

<a class="logo logo--horizontal logo--md" href="/home" aria-label="KeepExec home">
  <span class="logo-frame" aria-hidden="true"></span>
  <span class="logo-wordmark">KeepExec</span>
</a>

Accessibility

Logo meaning is contextual

Consumers decide whether a logo is informative, decorative, or a navigation link. The CSS only controls visual identity styling.

  • Use aria-label on logo links when the wordmark is hidden or ambiguous.
  • Use empty alt="" for decorative static logo images.
  • Keep clearspace utilities when placing logos near controls or dense chrome.
  • Validate inverse, footer, mono, and ink modes against the active theme.
