Badge Tag

Badge/tag CSS styles counts, labels, removable chips, status dots, sizes, shapes, and semantic tones. CSS owns presentation; the application owns selection, removal, filtering, and status meaning.

Source truth

Imports and package surface

Badge/tag is authored in src/components/badge-tag.css and ships through dist/components/badge-tag.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/badge-tag.css";

Examples

Status, count, and removable tag

Pair semantic color with text. Removable tags need a real button with an accessible name.

Synced Needs review 12 Enterprise 
<span class="badge-tag badge-tag--tag">
  Enterprise
  <button class="badge-tag__remove" type="button" aria-label="Remove Enterprise filter">x</button>
</span>

Accessibility

Runtime ownership

CSS cannot remove a filter, update counts, or define what a semantic badge means.

  • Use text such as "Needs review" rather than color alone.
  • Synchronize selected, disabled, and removed state in application code.
  • Announce filter changes or count changes when they alter visible results.
  • Use disabled state only when the underlying action is actually unavailable.
