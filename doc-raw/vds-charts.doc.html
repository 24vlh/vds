Data display

Charts

Chart CSS styles shells, headers, legends, axes, series hooks, loading, empty, and error states. CSS does not render chart data or provide data semantics.

Source truth

Imports and package surface

Charts are authored in src/components/charts.css and ship through dist/components/charts.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/charts.css";

Example

Labeled chart shell

Give SVG or canvas output an accessible label and provide a text summary when visual series are important to the decision. 

<figure class="chart" aria-labelledby="chart-title chart-summary">
  <h3 class="chart__title" id="chart-title">Support volume</h3>
  <p class="chart__subtitle" id="chart-summary">Volume rose 12 percent this month.</p>
  <svg class="chart__canvas" role="img" aria-label="Support volume by week">...</svg>
</figure>

Accessibility

Data and state ownership

CSS does not calculate values, create SVG paths, summarize data, or announce loading/error changes.

  • Do not rely on series color alone; include legend labels and written summaries.
  • Use aria-busy or nearby status text when loading chart data.
  • Application code owns tooltips, drilldowns, filters, live updates, and export actions.
  • Use empty and error states only when the data lifecycle requires them.
