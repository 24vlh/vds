Instruction

Guidance

Guidance CSS styles static instructional panels, briefs, comparisons, checklists, rows, scopes, stats, and steps. CSS owns layout and tone; product code owns decisions, validation, and actions.

Source truth

Imports and package surface

Guidance is authored in src/components/guidance.css and ships through dist/components/guidance.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/guidance.css";

Accessibility

Instructional content boundaries

Guidance CSS does not validate decisions, enforce checklist state, or announce changes.

  • Use clear text labels for do, don't, warning, and recommendation variants.
  • Application code owns decision logic, routing, validation, and action execution.
  • Use semantic lists for checklists and ordered steps when order matters.
  • Do not rely on tint or color alone to communicate importance.
