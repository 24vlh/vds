Disclosure

Accordion

Accordion CSS styles native disclosure groups built from details and summary. CSS owns the visual shell, density, status tone, and motion hooks; the document owns headings, summary text, and any non-native expansion behavior.

Source truth

Imports and package surface

Accordion is authored in src/components/accordion.css and ships through dist/components/accordion.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/accordion.css";

Accessibility

Runtime ownership

Native summary elements provide keyboard support. Application code owns any custom accordion model, analytics, route sync, single-open behavior, and live announcements.

  • Keep summary labels short and unique.
  • Use real headings around the accordion when the page outline needs them.
  • Do not replace summary with a generic element unless the app recreates keyboard and ARIA behavior.
  • Reduced-motion and forced-colors behavior comes from the CSS layer; validate custom content separately.
