Tabs

Tabs style tab lists, tabs, panels, active/hidden/disabled hooks, pill and segmented variants, vertical orientation, scrollable lists, icons, and badges. Activation logic is consumer-owned.

Source truth

Imports

Tabs are authored in src/components/tabs.css and ship through dist/components/tabs.css. 

@import "@24vlh/vds/dist/core.css";
@import "@24vlh/vds/dist/components/tabs.css";

Example

APG-compatible hooks

CSS supplies visual hooks. Application code owns roving focus, Arrow/Home/End/Enter/Space behavior, selected state, and panel visibility.

Profile settings are shown here.
Security settings are loaded by application code. 
<button class="tab tab--active" type="button" role="tab"
        aria-selected="true" aria-controls="panel-profile">Profile</button>

Accessibility

Runtime ownership

Keep tab--active, aria-selected, hidden, focus, and routing state synchronized together.

  • Use aria-orientation="vertical" when using vertical tabs.
  • Icon-only tabs need accessible names.
  • Scrollable tab lists still need keyboard access to every tab.
