Android Shell

Accessibility

Application-owned state

CSS does not route, filter data, update badges, select panes, or announce live status changes.

  • Synchronize aria-current, aria-pressed, disabled state, and badge counts in app code.
  • Use visible labels or accessible names for icon, filter, FAB, and nav controls.
  • Announce route, filter, and queue-count changes when they affect the user's task.
  • Validate safe-area behavior on real mobile viewports.
